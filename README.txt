ふたりの家計簿 Ver.0.2 — iPhone用PWA試作品

【内容】index.html / manifest.webmanifest / sw.js / icon-192.png / icon-512.png

【重要】
・この版は各端末のブラウザ内にのみデータを保存します。夫婦間の自動同期はありません。
・銀行・カードとの連携はありません。家族カードの支出は口座残高から自動控除されません。
・データ消失に備えて「分析」→「データを書き出す」で定期的にバックアップしてください。
・バックアップJSONには家計情報が含まれるため、第三者と共有しないでください。

【iPhoneのホーム画面に追加】
1. これらのファイルを同じフォルダ構成のままHTTPS対応の静的ホスティングに配置します。
2. Safariで公開URLのindex.htmlを開きます。
3. Safariの共有メニューから「ホーム画面に追加」を選びます。
4. 追加したアイコンから起動します。初回はネット接続が必要です。

【注意】
・HTMLファイルを「ファイル」アプリから直接開くだけでは、PWAのインストールとオフラインキャッシュは有効になりません。
・静的ホスティングで公開されるのはアプリのコードです。入力データはこの版ではサーバーに送信しませんが、ホスティング事業者と配信コードは信頼できるものを使ってください。
・Safariで開いた場合とホーム画面に追加した場合は、保存領域が異なることがあります。必要ならJSONで移行してください。
・オフライン利用は一度オンラインで正常に読み込んでから試してください。
・実データを長期運用する前にバックアップ・復元をテストしてください。
